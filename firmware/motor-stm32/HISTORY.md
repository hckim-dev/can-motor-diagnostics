# 모터 STM32 개발 기록

의미 있는 작업을 마치면 [공통 양식](../../docs/development-history.md)에 따라 기록합니다.

## 2026-11-20 · 방향 입력 해제에 따른 모터 정지 구조 설계

- **담당·근거** — 권민지(모터 STM32), 기존 `Core/Src/motor_control.c`의 `start`·`stop` 분기와 앞·뒤 버튼 해제 동작에 대한 설계 논의
- **문제** — 기존 구조는 `start`가 참일 때만 내부에서 `stop`을 확인했다. 시작 입력이 해제된 뒤에는 별도 STOP 입력도 검사하지 못하므로, 앞·뒤 버튼을 떼는 동작만으로 정지 절차를 시작할 수 없었다.
- **판단과 변경** — 버튼을 누르는 동안 앞·뒤 방향 신호를 주기적으로 받고, `MotorControl_OnDirection()`에서 마지막 유효 방향과 수신 시각을 기록하는 구조로 설계했다. 모터 태스크는 방향 신호가 만료되면 버튼 해제로 판단하고 저듀티 유지 후 두 PWM 채널을 0%로 내린다. 운전 허가 만료·철회나 비상정지는 저듀티 구간을 생략하고 PWM을 끄도록 구분했다. 예제에서는 두 입력의 만료 기준을 각각 200ms로 두었다.
- **검증** — 모터 태스크와 `main.c` 연결 예제는 ARM GCC 문법 검사를 통과했다. 로컬 펌웨어 반영, CAN 연동, 실물 버튼 해제 및 정지 검증은 미실행이다.
- **후속 검증** — `motor_control.c`와 `motor_control.h` 작업본을 추가했다. 두 파일은 STM32F103 프로젝트 헤더를 사용한 ARM GCC 문법 검사를 통과했다. 전체 펌웨어 빌드, CAN 연동, 실물 검증은 남아 있다.
