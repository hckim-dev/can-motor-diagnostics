# CAN DO — Project Plan

> CAN 기반 모터 제어·진단 검증 시스템의 기능별 개발·통합 **Baseline 계획**입니다.

## Overview

| 항목 | 내용 |
|---|---|
| 계획 기간 | 2026-11-18 ~ 2026-12-09 |
| 일정 기준 | 주말 제외 |
| 통합 수락 마감 | 2026-12-09 |
| 전체 작업 | 46개 |
| 기준 문서 | CAN DO 시스템 설계서 v1.3 본문 1~7장 및 부록 A~D |

> [!NOTE]
> 이 문서는 **2026-11-18 시작 시점의 Baseline 일정**을 정리한 계획 문서입니다. 원본 간트차트의 상태/진척률은 모두 `예정 / 0%`이므로, 실제 진행 현황을 의미하지 않으며 일정·담당·선행관계 중심으로 제공합니다. 작업 ID는 원본 WBS 식별자를 유지하며, 상세 표는 계획 시작일 기준으로 읽기 쉽게 배치합니다.
