# 시스템 구조

CAN DO 시스템 설계서 v1.5의 본문과 부록 C0를 기준으로 합니다. 기본 구성은 PC Qt, Jetson Orin Nano, 모터 STM32 NUCLEO-F103RB, Basys3입니다.

| 장치 | 역할 |
| --- | --- |
| PC Qt | 운전·정지·고장 해제·시험 준비 요청, 명령 결과와 모터 상태 표시 |
| Jetson backend | Qt 요청 검증, CAN 명령·운전 허가 발행, CAN·UART 수집, 시험 판정, 기록·리플레이 |
| 모터 STM32 | PWM·엔코더·전압·전류 처리, 모드와 허가 검증, 명령 실행 여부 결정, 고장 래치와 상태 보고 |
| Basys3 | 로컬 버튼으로 시험 시작, A/B 시험 파형 생성, 진단 응답 시간 측정, UART 이벤트 보고 |

## 운전과 시험

- **REAL**에서는 74HC157이 실제 모터 엔코더를 STM32에 연결합니다. STM32는 로컬 모드, 비상정지 입력, 전원 관측, 현재 운전 허가와 고장 상태를 확인한 뒤 새 운전 요청을 판단합니다.
- **TEST**에서는 물리 선택 스위치가 모터 6V를 차단하고 MUX가 FPGA A/B를 선택합니다. STM32는 PWM을 LOW로 유지하면서 같은 피드백 진단 경로로 시험 신호를 처리합니다.
- Qt의 `ARM_TEST`는 MCU 시험 준비 요청입니다. Basys3의 파형 시작은 로컬 버튼으로 수행하고, 자동 판정에는 CAN 상태·고장과 FPGA GPIO·UART의 관측 증거를 연결합니다.

물리 비상정지 NC1과 청색 전원 재투입 버튼은 릴레이 경로를 사용합니다. NC2 상태는 모터 STM32에서 읽는 방향이며 핀·전기 조건은 현물 확인 후 확정합니다. 실물에서 PWM 억제, 모터 공급 차단, 축 정지는 각각 계측합니다.

기본 구성에서 운전 허가와 CAN 명령의 송신원은 Jetson 한 대입니다. 조작 MCU 추가는 선택 확장이며, 추가 시 제어권 단일화와 버스 구성을 확정합니다.
