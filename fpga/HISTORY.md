# FPGA 개발 기록

## 2026-11-23 · FPGA 인수인계 자료 정리

- **담당·근거** — FPGA 기획과 [인수인계 안내](README.md#인수인계), [지그 구매 목록](../docs/assets/motor-test-jig-overview-v2.png).
- **문제** — 기존 스펙의 스위치 선택 흐름과 새 자동 시험 요구사항이 다르고, Vivado 프로젝트에는 보드 제약과 포트가 확정되지 않은 초안이 있다.
- **판단과 변경** — 설계 버전과 파형 자료, FND 표시 계획, 지그 구매안 및 Vivado 초안을 한 브랜치에서 인계할 수 있게 정리했다. 자동 실행 순서와 배치 재시작 신호의 미확정 상태를 기록했다.
- **검증** — XPR과 Top·하위 RTL의 현재 상태를 파일에서 확인했다. RTL 시뮬레이션·합성·실물 조립 검증은 미실행이다.

## 2026-11-20 · FND 표시 설계 v1.4

- **담당·근거** — FPGA 설계 항목. [구현 스펙 v1.4](../docs/FPGA_구현_스펙_v1.4.md), [모듈 구조](FPGA_모듈구조.md), [연결도](FPGA_모듈_연결도.svg).
- **문제** — 로컬 Vivado 초안은 FND 컨트롤러를 참조하지만 시험 상태의 표시 형식과 구동 조건은 문서화돼 있지 않았다.
- **판단과 변경** — 시나리오·phase·READY·DIAG의 4자리 표시와 FPGA 무효·중단 표시를 정했다. v1.4는 FND를 독립 출력 블록으로 연결하고 Basys3 핀 매핑과 검증 항목을 명시한다. FND 신호의 공급 모듈과 포트를 연결도에 표시하고 스펙 Markdown·PDF 본문에 수록했다.
- **검증** — Digilent 문서에서 FND 핀 순서와 active-low 극성을 대조했다. FND RTL 구현, Vivado 시뮬레이션 및 보드 점등 검증은 미실행이다.

## 2026-11-19 · FPGA 모듈 구조와 배선 문서 정리

- **담당·근거** — FPGA 설계 항목. [구현 스펙 v1.3](../docs/FPGA_구현_스펙_v1.3.md), [모듈 구조](FPGA_모듈구조.md), [연결도](FPGA_모듈_연결도.svg).
- **문제** — 전체 처리 흐름과 개별 모듈 도식만으로는 신호의 출발점과 연결 대상을 한눈에 확인하기 어려웠다.
- **판단과 변경** — 기능별 9개 모듈의 입출력과 동작을 기술하고, 공통 신호와 UART 경로의 수락 신호 방향을 연결도에 표시했다.
- **검증** — 문서와 도면의 모듈명, 대기열과 UART 수락 신호의 방향, 스펙의 UART 골든 벡터 CRC 및 GAP_500의 512.5 ms 에지 간격을 대조했다. RTL 시뮬레이션과 실물 계측은 미실행이다.

의미 있는 작업을 마치면 [공통 양식](../docs/development-history.md)에 따라 기록합니다.
